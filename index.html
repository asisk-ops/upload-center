    How dealers send data
    1. CSV only. In Excel or Google Sheets: File > Download / Save As > CSV.
    2. Headers spelled exactly, with underscores and no extra spaces or characters. Case and column order don't matter.
    3. Email header on every list, even when there are no email addresses.
    4. Service type: include service recommendations when they're provided.
    5. One list type per file. Don't mix recalls and declined services.
